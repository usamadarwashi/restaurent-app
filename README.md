▶️ طريقة التشغيل خطوة بخطوة

1. تحميل Node.js (خطوة لمرة واحدة فقط)
   إذا لم يكن لديك Node.js مسبقًا:

ادخل إلى: https://nodejs.org

قم بتثبيته مثل أي برنامج عادي

2. فتح المجلد وتشغيل الخادم
   افتح المجلد الذي يحتوي على الملفات (مثلاً C:\RestaurantSystem)

اضغط بزر الماوس الأيمن أثناء الضغط على Shift واختر:

"فتح نافذة PowerShell هنا" أو "Open Terminal Here"

اكتب الأمر التالي واضغط Enter:
node server.js

✅ سترى رسالة مثل:
Server running at http://localhost:3000

3. فتح النظام
   افتح متصفح الإنترنت (Chrome أو غيره)

اكتب في شريط العنوان:
http://localhost:3000

وسيفتح لك النظام مباشرة.
